# Contracts: README Documentation Links

This feature introduces no API changes.

## Contract: Documentation Links

The repository README MUST link to canonical documentation under the `docs/` directory.

### Required link targets

- `docs/API_DOCS.md`
- `docs/CONTRIBUTING.md`
- `docs/DEPLOYMENT.md`
- `docs/PROJECT_SUMMARY.md`
- `docs/AUDIT_REPORT.md`

### Invariants

- Links MUST use relative paths.
- Link targets MUST exist in the repository.
- Link labels SHOULD match the destination document titles.
